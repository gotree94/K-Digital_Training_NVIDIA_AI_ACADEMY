## 1. 교육 과정 개요

### 1.1 교육 목적

NVIDIA AI ACADEMY는 NVIDIA의 공식 교육 기관인 **NVIDIA Deep Learning Institute (DLI)** 를 중심으로 구성된 실무 중심의 K-디지털 트레이닝 과정입니다. C/C++와 파이썬부터 머신러닝, 딥러닝, 영상처리, 자연어처리, 강화학습에 이르기까지 AI 개발 전 과정을 학습하며, NVIDIA GPU 가속 컴퓨팅 기술과 실무 프로젝트를 통해 현장에서 바로 활용 가능한 인공지능 엔지니어 양성을 목표로 합니다.

### 1.2 교육 일정 구조

```
기초 언어         →  딥러닝/인공지능    →  심화 모델 설계    →  NVIDIA DLI    →  종합 프로젝트
(152시간)            (104시간)            (146시간)            (272시간)        (288시간)
```

### 1.3 주요 학습 역량

| 구분 | 세부 역량 |
|---|---|
| 프로그래밍 | C, C++ 메모리 관리, 파이썬 데이터 분석 환경 |
| 임베디드 | 하드웨어 이해, 센서/제어, Jetson 엣지 디바이스 |
| 딥러닝 | 머신러닝/딥러닝 이론, TensorFlow 구현, 영상처리 모델 |
| 고급 AI | GAN, 객체인식, NLP, 강화학습 |
| GPU 컴퓨팅 | CUDA C/C++, CUDA Python, 멀티 GPU, Model/Data Parallelism |
| 엣지 AI | Jetson Nano 활용, Edge Video AI, 산업검사 |
| 산업 응용 | 이상탐지, 예지보전, 사이버보안 |
| 실무 프로젝트 | AI 챗봇 개발, 영상처리 프로젝트 |

## 2. C, C++, 파이썬 및 임베디드 시스템 이해 (152시간)

## 3. 딥러닝 및 인공지능 (104시간)

## 부록 B. 자주 묻는 질문 (FAQ)

**Q. 프로그래밍 경험이 전혀 없는 사람도 들을 수 있나요?**
A. 과정이 C 언어 기초부터 시작하므로 프로그래밍 입문자도 학습할 수 있도록 구성되어 있습니다. 다만 매일 복습과 실습 참여가 중요합니다.

**Q. NVIDIA DLI 과정은 별도 시험이 있나요?**
A. DLI 과정은 실습 중심으로 진행되며, 과정별 과제를 완료하면 NVIDIA 공식 수료 인증서를 받을 수 있습니다.

**Q. 과정 수료 후 어떤 자격증/수료증을 받나요?**
A. K-디지털 트레이닝 수료증과 NVIDIA DLI 과정별 인증서(총 16개 과정)를 취득할 수 있습니다.

**Q. 프로젝트는 어느 정도 수준까지 진행되나요?**
A. 실제 배포 가능한 수준의 챗봇(웹 서비스)과 실시간 영상분석 시스템(데모)을 목표로 하며, 최종 발표와 데모 시연으로 평가가 이루어집니다.
